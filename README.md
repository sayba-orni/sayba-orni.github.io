# Sayba Kamal Orni — Portfolio

Interactive GitHub Pages portfolio with filterable PCB, robotics, and medical AI projects.

## Deploy
Upload the contents of this folder to the root of `sayba-orni.github.io`, then enable GitHub Pages from the main branch root in repository Settings → Pages.

The images under `assets/img/` are included. Replace the Medical AI placeholder graphics with your own research figures if desired. Update `assets/docs/CV.pdf` with your latest CV.
